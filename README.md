# Estrategia societaria - Make-Optic y Visualens

Expediente de trabajo para elaborar un informe jurídico-económico y una estrategia de salida en defensa de José “Pepe” Hernández Ferrer.

## Inicio

1. Leer la [issue Master](https://github.com/FarinosV44/estrategia-societaria/issues/11).
2. Revisar el [índice documental](documentacion/INDICE_DOCUMENTAL.md).
3. Ejecutar las issues especializadas antes del informe final.
4. Contrastar cualquier conclusión con los archivos de `documentacion`.

## Objetivo

Comparar negociación, saneamiento, adquisición de la óptica, liquidación, concurso y vías societarias/arbitrales, buscando que Pepe conserve una óptica viable, preserve sus créditos y limite su exposición como administrador y avalista.

## Precaución

Las cuentas están incompletas y las dos sociedades han funcionado con operaciones entremezcladas. Las extracciones textuales no sustituyen a los originales. No tratar saldos contables, notas manuscritas ni manifestaciones del cliente como hechos definitivamente acreditados.
